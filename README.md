# Samantha Ellis — Computational Materials Chemistry

This repository contains the source for Samantha Ellis's research portfolio. GitHub Pages builds and publishes it automatically after changes are pushed to `main`.

To work on it locally, install Node.js 22, run `npm ci`, then `npm run dev`. To check the static site that GitHub Pages publishes, run `npm run build` and inspect `out/`.

The current custom domain is `samanthaellis.org`. Domain DNS should only be changed after the GitHub Pages version has been checked. This repository does not automatically sync edits made in ChatGPT Sites.
